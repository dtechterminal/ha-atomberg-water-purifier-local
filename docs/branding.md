# Brand images

The integration bundles the Atomberg icon and light/dark logos from the [Home Assistant brands project](https://github.com/home-assistant/brands), served at `https://brands.home-assistant.io/atomberg/`. These existing PNG files are included unchanged, with normal and high-resolution variants.

The Atomberg name and logo belong to Atomberg Technologies. They identify the compatible product; this community integration is independent of Atomberg. Brand artwork is not covered by this project's MIT code license.

Home Assistant 2026.3 and newer can serve these files directly from the integration's `brand/` folder, including when the internet is unavailable. See the [Home Assistant announcement](https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/).
